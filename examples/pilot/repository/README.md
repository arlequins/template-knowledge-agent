# Fleet Desk Pilot

Fleet Desk Pilot is a public evidence-grounded knowledge-agent fixture. It
combines Fumadocs operating notes with a small T3-style TypeScript application
so a generated repository can prove documentation and source-code retrieval
before indexing private material.

The assistant must cite project files for repository questions, canonical
official pages for React and Drizzle questions, and an approved live capability
for current notices or sold vehicles. Static source code cannot prove that a
record currently exists.
